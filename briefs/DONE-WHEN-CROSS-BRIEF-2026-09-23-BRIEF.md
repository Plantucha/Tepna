# A Done-when item answered in a sibling brief

## 1 · The defect, and why it is structural

A Done-when item stayed open for **9 days** after the work satisfying it had been done and written
down — in a different brief. `PAT-FORENSICS-AXIS-LEG-ASYMMETRY`'s *"ECG ppm refusal rate re-measured
(the comment's 160/187 · 48 ms)"* was answered by `PAT-FORENSICS-FIDUCIAL-JITTER` §6, which
re-measured it on an independent 448-fragment population and prints the comparison outright. Neither
file knew. The only way to notice was reading both in one pass.

The residue row states the class: **a Done-when item names a QUESTION, and questions do not respect
brief boundaries**, while a checkbox is only ever cleared by the session that owns the file it sits
in. This brief asks whether that class can be detected, and answers **no — not by this shape**.

## 2 · Why a third attempt was affordable at all

`BRIEF-CODE-ANCHOR-CHECK` is a DONE negative that refuted two shapes: an identifier-existence check
(15/15 false positives, zero sensitivity on its own defining case) and semantic-over-extracted-claims
(§10 — the discriminator UNDEFINED for 10 of 19, margins smaller than the index's own movement). Its
§10.5 is the sentence to hand anyone proposing a brief checker:

> **Briefs are not descriptions of CODE. They are descriptions of WORK.**

That refutes brief→**code**. This shape is brief→**brief**, and the reason it was worth one
measurement is that §10.1's *finding* is this shape's *premise*: "a brief's claim retrieves briefs
because the corpus is brief-dense and briefs discuss each other." The property that defeated the code
detector is the signal here. ⚠️ It is also, in the end, exactly why this one fails — §6.

## 3 · §10.4's precondition was met: the plants came first

§10.4 binds any third attempt — **plant a known-stale case first**, because a detector whose
sensitivity is unmeasurable is a confidently-quiet failure whose silence reads as *"nothing is stale"*.

§10.3's control had been **consumed**: fixing the defining instance destroyed the only ground truth,
and `doc-search`'s index cannot be rewound. **These controls are recoverable, and that difference is
the whole reason this attempt was cheap.** The criterion below is LEXICAL over file contents, so git
replays the pre-fix tree exactly. Both plants are authentic history, not synthetic cases.

## 4 · The pre-registered criterion (fixed before the live tree was scanned)

```
ITEM      a markdown checkbox line: "- [ ]" (open) or "- [x]" (met)
TOKEN     a rare literal of a FIXED grammar — ratio (160/187), percent (85.6 %),
          measurement-with-unit (48 ms)
EXCLUDED  dates, #NNNN, §1.2, vN.N, bare years — BY CONSTRUCTION, not by precision:
          fixed grammars carrying no claim
RARE      the token occurs in >= 2 and <= 4 briefs (a token in many briefs is shared
          vocabulary, not a link). The bound is pre-stated, never fitted
CANDIDATE an OPEN item in brief A carrying rare token T, where T also occurs in brief
          B != A in a MET item or a table row — somewhere reporting a RESULT
```

**Bands, pre-stated:** sensitivity — the plant MUST be flagged, else FAIL (zero sensitivity is
disqualifying on its own, as the identifier check showed). Precision, every candidate inspected:
**≥ 50 % genuine ⇒ PASS · ≤ 20 % ⇒ FAIL · otherwise UNKNOWN**. Zero candidates *with* the plant
flagged ⇒ **UNKNOWN, never PASS** — a floor cannot detect exclusion and an empty result is not a
negative.

Two exclusions are available **by construction** (not by precision): a ratio that is a code anchor


**Precision after both exclusions: 0 of 2.** The survivors are #1 and #4 — and they are false for a
reason no exclusion reaches.

## 6 · Why it fails: the token is not the claim

Both survivors share a number **because briefs cite each other's numbers**. `39.1 %` appears in two
briefs precisely because both are quoting #1030; `39–128 ms` appears in two because both cite §3e.
That is §10.1's brief-density property again — and it cuts the other way. The same corpus structure
that makes a cross-brief link *retrievable* makes a shared token *non-discriminating*: in this corpus
a repeated number is evidence of **citation**, which is the null hypothesis, not of **answering**.

And P2 shows the complementary hole: when two briefs genuinely describe one change, they routinely
share **no token at all**, because each names it in its own vocabulary. So the shape misses the
hardest real cases and fires on the easy unreal ones — the two errors are not independent, they are
the same fact about how briefs are written.

## 7 · What a fourth attempt owes

1. **Do not key on a shared literal.** Measured here: in this corpus a shared number means citation.
2. **Plant BOTH directions.** P2 — same change, different words — is the case that matters and the one
   a lexical shape cannot see. A fourth attempt is not credible without a plant of that kind, and
   P1-only sensitivity would have read as 1/1.
3. **Verify each plant was SEEN.** The first P2 run was vacuous (item already met) and would have been
   reported as a miss.
4. The remaining honest shape is **social, not analytic** — bind the session that EXECUTES an item, as
   §📌 already binds the session that TRIAGES a brief. Residue
   `2026-09-13-executing-session-stamps-nothing` records exactly that gap, and it is where this class
   should be attacked next. That is a CLAUDE.md change, not a detector.

## 8 · Limits of this negative, stated

- **Precision n = 4 distinct items** (2 after exclusions). Small. It is decisive only because every
  candidate was read individually and each failure has a *named mechanism*, not because 0/4 is
  statistically strong on its own.
- **Sensitivity n = 2** — the class's two recorded instances. There may be more in the ledger; these
  are the two written down.
- **One token vocabulary was tested** (ratio · percent · measurement). A different extractor might do
  better, and that is **not** refuted here — but §6 is an argument about the corpus, not the regex,
  and any replacement owes §7.1.
- **The detector is deliberately NOT shipped.** It is refuted, and a refuted instrument left in
  `tools/` invites being wired into a gate, where its silence would read as "no stale items". §4 is
  the whole criterion and §3 names both refs, so the measurement is reproducible without it.

One front end for the mutation lane — `tools/mutation-suite.mjs` — plus the two fixes that make the
existing machinery actually usable unattended. **This reuses; it does not replace.** `mutate.mjs`
(2032 lines) already owns mutant generation, the worker pool, the journal, `--resume` with
jammed-mutant quarantine, the heartbeat and coverage-directed selection; `extreme-mutate.mjs`,
`stmt-delete.mjs`, `per-group-coverage.mjs`, `mutation-crawl.mjs` and `mutation-worklist.mjs` each
own a real piece. What did not exist was a driver that ties them together and survives an overnight
run. Each item below is a gap measured on the 2026-08-16/17 fleet crawl.

**FAST — the coverage map existed and no sweep had ever seen it.** `.mutation-sweeps/per-group.json`
(1.76 MB, built 2026-08-14) is an **untracked** artefact, and every sweep here runs from a private
worktree (CLAUDE.md §👥.1) — a fresh tree that untracked files do not follow. So the 10–100× path
MUTATION-PROGRAM-FOLLOWUPS §6 calls a *prerequisite* has been dead since the reboot, invisibly:
`mutate.mjs` treats an absent map as "no selection" and falls back to the tag filter, which fails
safe into *slow*, never into *wrong*. Measured cost: ecgdex 290 min, oxydex 193 min, both unselected.
`tools/mutation-map.mjs` now resolves the map from the **git common directory**, which every worktree
of a repo shares.

**…and the map now carries an identity, because a stale one fabricates findings.** It was written
`{ generated: null }` with no hashes at all. The two failure directions are not symmetric: an
**absent** map costs time, while a **present, stale** map selects groups that do not execute the
mutant's line — and a mutant no test executes SURVIVES. A map is a function of line numbers, and
lines move for reasons as trivial as a comment (#1422 inserted 16 into `oxydex-dsp.js`, shifting
everything below 1023). It is now stamped with a hash per mapped source **plus `tests/dex-tests.js`**
— the map's values are group INDICES, so inserting a group shifts them all, which no per-file source
hash would catch — and verified **per file**, so one moved DSP does not cost selection on the other
seven. Unstamped maps are refused: they may be perfectly good, and there is no way to tell.

**UNSTUCK — it flags a stall and resumes itself.** A probe once wedged for 11 h 11 m of CPU at 93 %
with no output and no result, blocking two files from ever being crawled; nothing noticed, because a
hung run and a slow run are indistinguishable from outside. The watchdog decides on the only signal
that separates them — whether the **journal is still growing** — not on elapsed time and not on CPU.
On a stall it kills the child, records it, and resumes; `--resume` quarantines the jammed mutant, so
the retry makes progress instead of re-entering the hole. Bounded by `--max-restarts` (default 3),
because a watchdog that restarts forever is just a different way of hanging.

**KILLABLE — by PID, matching no pattern.** `pkill -f` is the self-match deadlock of CLAUDE.md §👥.4
(measured: six mutually-blocked waiters with zero pytest processes running). The suite writes a PID
file; `--kill` reads it and signals those PIDs. The journal is left intact, so the next run resumes.

**VERBOSE — every mutant named, and every kill attributed.** `mutate.mjs` streams SURVIVED lines but
never says what KILLED a mutant, although the journal has recorded the killing group all along. Each
line now carries `file:line`, the operator, the source either side of the change, and
`killed by: "<group>"`. A kill you cannot attribute teaches nothing; an attributed one tells you which
assertion is load-bearing. Plus rate, ETA, running kill counts, and a heartbeat.

**THE PUBLIC LIST — `docs/MUTATION-INVENTORY.md`, generated by `--inventory`.** Everything this lane
knew lived in gitignored journals, an untracked map and `/tmp`, so "what does the suite know about our
tests?" was never answerable from the repository. The list is generated (a hand-kept list of thousands
of mutants goes stale silently — the exact failure this lane exists to expose) and **self-locating**:
it states where the driver lives and every command needed to reproduce it.

⚠️ **Two of my own defects, both caught by planting mutations against the new assertions:**
`mutation-map.mjs` ran its selftest **on import**, so `mutation-suite.mjs --selftest` executed the
*map's* assertions, called `process.exit`, and reported "all green" for suite tests that never ran —
a check that examined nothing and reported cleanly. And the inventory first inferred "partial" from
`inFlight > 0`, which is **not** a running-signal: a finished ecgdex sweep still ends with one
unverdicted START (the quarantined jammer), so it flagged 4 of 4 files partial when 1 was. Completion
is now a **recorded** marker written on clean exit, with a third state — `unknown` — for journals this
suite did not finish itself. Unknown is not a euphemism for unfinished; it is the honest statement
that nothing here can vouch for it.

Local models are wired for **one** narrow job: `--cluster` groups survivors by shape using a local
embedding model so a reader writes one test per family instead of reading 1477 lines. It is marked
ADVISORY everywhere and decides nothing — calibrated on this repo it scored 0/4 judging code
correctness and 0/3 counting. If the model is unreachable it **refuses**, and never degrades into a
text heuristic wearing a model's output.

Measurement tooling only: no DSP, no test, no bundle, no ledger.

coospo-rr and wahoo-rr matched their vendor token anywhere in a file's first 2 KB of content, so the capture host's own BLE link log — which lists every paired peer by advertised name — routed as an RR recording at 0.95 with ambiguous:false (9 of 326 files on two real capture nights). The token must now name the FILE or appear on its HEADER LINE, restoring the asymmetry the three Polar adapters always had.

Four analysis tools declared their population unit as a file and then printed that same count as `night(s)`.
Each now names the unit it counts, and `ppi-jitter-vs-ecg.mjs` takes its word from the merge mode, because `--no-merge` makes a row a file.
A suite block names every genuine night claim the four may print, so the label cannot come back.

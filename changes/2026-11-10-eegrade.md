The EEGDex surface stated three claims it cannot support. Each one is now the claim the node can make.

The hypnogram wrote a confidence of 0.5 on every scored epoch. `hypno-export.js` states the fleet contract: `confidence` is the posterior of the decoded stage, and a stager without posteriors reports null. This stager is a band-power rule set, so it holds no posterior. The flat 0.5 was an in-range sentinel. `hypno-export.js` draws a darker strip for a surer epoch, so a consumer that reads the number treats it as a measurement. EEGDex routes nothing through that module today, so the defect is the value and the assertion that pinned it, never a drawn claim.

Every epoch now states null. The node-export already refused to copy the 0.5 onto the bus, so nothing downstream carried it.

The registry declared the unit of `totalPower` as µV². The DSP carries the EDF channel's own physical dimension, and the power tile prints a squared unit only when the header declares one. So two single sources disagreed, and the registry asserted a calibration this node never measures. The registry now states a squared amplitude, and the cite names the EDF header as the source of the unit.

`remPct` carried the grade `validated`, over a cite that argues PSG EEG staging is the reference standard. That cite grades the method, not this stager. Its three siblings from the same hypnogram each read `emerging`. The cite of `tst` states the rule: a metric from the staged hypnogram inherits the stager's tier. `remPct` now reads `emerging`, and its cite states the inheritance.

The suite pinned the 0.5 as a deliberate placeholder. It now pins the absence over the whole population: no epoch carries a number, and the count covers all 60 epochs.

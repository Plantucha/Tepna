The fused report names the optical site of every corner, lane and consensus row. A three-cornered hat
tagged two corners of one node with four keys that no normalized record carries, so both optical
corners read `PpgDex 1` and `PpgDex 2`, in load order. The tag reads the site that the dedupe rule
already reads, so a Muse headband night reads `PpgDex forehead` beside `PpgDex wrist`. The per-source
rows and the node chips and timeline lanes carry the site too. `siteSource` travels beside it, and it
names this layer as the author when an export declared no site at all.

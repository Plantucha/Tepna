Re-judging a past night no longer borrows the next night's doff. A night's morning folder also holds the
following night's evening, and once that night has been audited its loss audit names the following
night's doff as the worn end. The judge adopted it, the band clipped it to 10:00, and the H10 and the
Verity on 2026-10-05, both doffed at 04:20, read "51.7 % complete" and failed. Only the files whose
session starts inside the judged band now cross from the morning folder, and a foreign worn end is
re-derived over those, using the loss audit's own rule. A between-fragments gap row that names no
file crosses only when the gap ends inside the band, so the 13 h boundary from 10-09's doff to 10-10's
evening no longer fails 10-09.

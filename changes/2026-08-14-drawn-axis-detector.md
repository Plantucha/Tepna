`hostAxis` can now tell a device column that is a clock from one that was drawn. Found by running the known-clock experiment against a real three-device box night: `independent` was `spreadMs > 2 ms`, which detects the OPPOSITE of what it must for a fabricated axis — a counter synthesised as `index x an assumed rate` at 1 s granularity produces an enormous residual spread, so the coarser the fabrication the more independent it read. Measured on the O2Ring's real monotonic run: `ok:true, ppm = 2765.5, independent:true` — a confident rate for a device with no oscillator, consumed downstream by `pat-gate.js`, `ecgdex-dsp.js`'s fs correction and `integrator-dsp.js`'s skew decision. The whole-file run refused only by luck (a mid-session counter reset makes the device span negative, tripping the plausibility bound); on the monotonic segment a node actually parses, it sails through. `hostAxis` now computes the modal-delta concentration from the anchors it already holds and publishes `drawnShare`, `deviceDrawn` and `drawnReason`. The bound `0.67` is measured, not chosen: over 381 arrival sidecars the 356 real clock streams top out at **56.00 %** and the 25 drawn ones bottom out at **79.04 %**, with nothing between — 0/25 missed, 0/356 false positives. This also shows the pre-existing >=99 % drawn test misses **5 of those 25**, since one counter reset or repeated stamp drops a genuinely fabricated stream to 79 %. `deviceDrawn` is published ADDITIVELY and deliberately does NOT gate `independent`: folding it in was implemented and reverted because it reds 11 assertions including ECGDex's planted-drift recovery, whose fixture legitimately uses a uniform device axis — the detector is right about real data and wrong to be load-bearing against a fixture. The remaining hole is asserted explicitly in the new test group so it cannot be closed silently without migrating consumers. Also recorded: `Verity ppi` is 100 % drawn, a second fabricated stream not previously flagged.

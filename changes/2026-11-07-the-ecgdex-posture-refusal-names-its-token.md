An ECGDex epoch wrote a posture reason under one branch only, the recorded blanking run. Three other paths reached the same `unknown` and named nothing. They are no companion accelerometer at all, a stream too short for one window, and a window this node lacked samples for. The shipped rich fixture carries the first of those as a bare `unknown`. The position lookup promised the distinction in its own comment. The early return handed it a populated list of `unknown` instead, so no consumer could keep it.

Each refusal now names its own token. A gravity vector scored against every class and matched to none stays silent, because that is a measurement. The exported epoch and the surge event both carry the token, present only on a refusal, so a measured epoch keeps a byte-stable shape.

A measured epoch deletes the key rather than keeping it. A late companion re-stamps the same epoch objects, so a token from the accelerometer-less first pass would otherwise outlive the state that earned it.

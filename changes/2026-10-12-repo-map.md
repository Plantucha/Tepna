**Every source file, its functions and its exports — one map, and it decides nothing.**

`tools/repo-map.mjs` lists the functions and the exports of each source file. JavaScript reads by
regex, and the method cell says `regex` and `approximate`. Python reads through the `ast` module in
one isolated interpreter, and the method cell says `ast`.

It writes no `tepna.verdict/1` object. A map states what it found, and it decides nothing, so an
object with a `status` would overclaim.

Absence is null, never a zero. A file with no symbol carries `symbols: []`, which is a measurement.
A file this tool could not read carries `symbols: null` and a named reason. Without `python3` every
Python record is null, under the reason `python3-absent`. A file that holds function-shaped tokens
and no named declaration carries a note, so a form the scan cannot read never reads as a zero.

`__all__` has three states: absent, a literal, and not a literal. Each file states the basis of its
export list.

Discovery runs through `git ls-files`, so a file written this session is in the map and an ignored
build product is not. Without git the tool walks the tree and labels the fallback.

Measured on 918 files: 426 JavaScript by regex, 492 Python by ast, 20472 functions and 12496
exports, in 0.9 s. Flags: `--summary`, `--only`, `--symbol`, `--json` and `--selftest`. 35 selftests.

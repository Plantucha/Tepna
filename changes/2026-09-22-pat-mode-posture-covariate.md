`tools/pat-mode-posture.mjs` — the posture covariate PAT-FORENSICS-WINDOW-ORACLE §-park asked for (residue `2026-09-06-a-statistic-both-hypotheses-predict`): the per-night lag mode is predicted by both slow physiology and a host-invisible instrument effect, so the oracle could not separate them. This asks a question whose answer differs — when the trunk (H10 chest ACC) returns to a posture held earlier, does the mode return with it? Per-night ratio of median |Δmode| over same-posture pairs to adjacent different-posture pairs, a within-night permutation null, bands pre-registered before the first corpus night was scored, population as an equality with every skip named. Adopted in `verdict-adoption.json`.

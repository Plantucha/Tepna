HRVDex nulls every value on a measurement whose upstream node recorded a clock seam, and it writes the reason beside the nulls. No HRVDex surface read that reason. A refused row drew the same em-dash and the same chart hole as a source column that never carried the metric.

The alert panel now leads with what the node did. A refusal line counts the rows it nulled and names the token. An UNKNOWN line counts rows whose upstream block reports no seam number, under the upstream's own word. A third line counts rows that arrived with no upstream block at all.

Every line states its population against the loaded set, so a count never reaches the reader alone. A measured zero stays silent, because a banner on every clean dataset buries the lines that matter.

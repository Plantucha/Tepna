The 8 OxyDex tiers #2083 deliberately held below its own grading rule are ruled and raised — each on a
ground independent of that rule (FOLLOWUPS §2.5 table).

#2083 registered 35 metrics graded from the code and, where its rule would have RAISED a badge, left
the guide's lower grade standing: understating trust is never fabricated authority, and raising one on
a rule written that afternoon is what the badge mandate forbids. The 8 were tabled with the code line
for each so the decision could be made deliberately, by someone other than the rule's author. Ruled
2026-09-02 by Kestrel, all 8 raised:

| metric | now | ground |
|---|---|---|
| MODL · HR Nadir Timing | `measured` | existing registry precedents of the same shape — `nadirDepth` ("mean depth of those nadirs, in the sensed unit") and `minSpo2` ("lowest recorded — direct reading"). A mean of sensed values over a threshold-defined set is measured; the threshold belongs to the DETECTION metric (odi3), not to the mean |
| LF / HF Power · Circadian HR Amplitude | `experimental` | the `dfaAlpha1` precedent verbatim — an established method (Task-Force bands, cosinor) transferred to oximeter pulse rate keeps the transfer named rather than inheriting the method's standing |
| O₂-HR Efficiency · RMSSD Arc · SPI · Vagal Index | `experimental` | CLAUDE.md §🎫's own retired-vocabulary mapping `composite→experimental`; a bespoke composite at `heuristic` understates the house definition |

Each ground is recorded in the entry's own `cite`, so the reasoning travels with the grade instead of
living only in a brief. Registry and guide cards move in lockstep (`cohesion-badges` asserts equality,
so a one-sided edit reds). **Registry ids are unchanged**, so no export identity moves, and no card
text changes — this is a tier decision, not a description fix.

The A2 SPDX lint now enumerates its own scope. It used to read `env.sources` — a list curated to feed
unrelated source-scan gates — so a file was licence-checked iff some other scan happened to need its
text, while `CLAUDE.md` §📜 states the invariant as universal. Measured: 124 of the tree's 203 authored
`.js`/`.mjs` were covered, and **all four** headerless files sat in the uncovered 39 %, two of them
(`how-to-collect/image-slot.js` and its generated `docs/` mirror) in no scan list at all. A2 now walks
the tree with the same walker `docs-ledger` uses, with three anti-vacuity legs; the four headers are
added. Also: `build.mjs` honors every repeated `--app` (it took only the first and exited 0, which is
how OverDex drifted on #808) and validates all names before writing any bundle; and
`tools/regen-goldens.mjs --all` runs one child process per node with a single combined summary that
keeps `NOT REACHED` distinct from `skipped` — 11 unreached fixtures across 7 nodes are now one line
instead of a nine-node shell loop.

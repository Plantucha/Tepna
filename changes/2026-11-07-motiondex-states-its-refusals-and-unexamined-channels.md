MotionDex refuses the immobile fraction when a device-clock seam crosses the recording, and it names the reason beside the null. It refuses a whole position or actigraphy block when the accelerometer unit stays unknown, and it names that reason too. The render file read none of those keys. A refused figure drew the em-dash a night with no covered epoch draws, and a refused block drew the nothing an absent stream draws.

The Signal Quality card now leads with what the node refused. A refusal states the node's own token and tells the reader the em-dash above it is that refusal. It also says the movement index still stands, because a magnitude over covered epochs is not a span.

An unexamined seam channel reads UNKNOWN under the reader's own token, and the figures above it stand. A recorded seam count, a device-clock step and a blanked epoch each annotate with their count. A seam count whose placement nobody published reads UNKNOWN rather than zero. A night measured clean on every channel draws no note, because a note on every clean night is noise.

The card now opens on the note alone. It used to open only once a signal-quality figure arrived, which hid a refusal on the very night that earned it.

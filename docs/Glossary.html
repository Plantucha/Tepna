Glossary

The words this suite uses, and what each one is bound to.

Tepna is a fleet of single-signal analyzers that share one spine. The vocabulary below is not decoration — each term names a role in that spine, and using the wrong word usually means reaching for the wrong part.

This page is a render, not a source. Every definition here is carried from a document that is already authoritative: the naming system from docs/LEXICON.md, the evidence ladder from dex-badges.css, the time model from the Clock Contract. Where this page and its source disagree, the source wins and this page is the bug.
It defines no per-metric clinical term on purpose — a metric's identity, unit and evidence tier are node facts owned by that node's registry, and restating them here would fork a table that is required to have exactly one source.
The metaphor

One nervous system

Read end to end, the suite is a literal reflex arc. The names already encode it, which is why they are worth learning once.

afferent · receptors
the -Dex nodes

Each senses exactly one signal and reports it inward. A receptor does one transduction well — that is why a node is single-signal.

relay
Ganglior

The event bus. Ganglia are the nerve junctions where signals are routed; this is where node exports converge as events.

integration centre
the Integrator

Afferent signals converge and become one coherent percept — the cross-signal picture no single receptor can produce.

efferent · insight
“Tepna”

The read-out. It names what the system produces, not a fourth product standing next to the nodes.

This is the same arc a knee-jerk follows: receptor → relay → integration → response.

Trust

The evidence ladder

Every number this suite shows you wears an evidence badge — every KPI, every card, every chart series, every table row. The disc shape encodes how much the number can be trusted, so the trust channel never collides with a status colour. Five tiers, ordered most to least trusted:

  • rank 0measuredA direct sensor reading or a raw statistic of the recorded signal — mean, min, max, nadir, duration. Ground truth, not computed.
  • rank 1validatedAn established, externally validated, clinically meaningful derived metric.
  • rank 2emergingPublished and promising, but less standardized or device-dependent.
  • rank 3experimentalA plausible node-computed composite that has not been externally validated. Directional only.
  • rank 4heuristicA convenience estimate or population proxy. A trend, not a measurement.
The order is frozen and the vocabulary is closed. Retired words — proxy, composite, provisionally validated — must never reappear; they map onto heuristic, experimental and emerging respectively. A tier is a fact about a metric, recorded once in that node’s registry, and no document may re-grade it.
Terms

One-line glossary

-Dex node
A single-signal afferent receptor. It senses one physiological signal and emits events. OxyDex senses oxygen, ECGDex cardiac electrical activity, PulseDex raw beat-to-beat timing, GlucoDex glucose, CPAPDex therapy data, MotionDex inertial motion; HRVDex summarizes variability.
Ganglior frozen name
The relay / event bus where node exports converge. The name is frozen and is not a candidate for renaming; a fascia input alias is read for backwards compatibility only.
Integrator
The central integration layer. It fuses afferent nodes into a longitudinal, cross-signal percept.
Tepna
The name for the system’s autonomic read-out — the product brand, and the tagline for what the suite produces. It is not a node, and it is a distinct thing from the frozen bus codename above.
Metric registry
The per-node declarative map that gives each metric its label, unit, direction, depth and evidence tier. It ships inside the app and is the single source for all four; every other surface is a projection of it.
Depth
How much you see: Core · Advanced · Research. Progressive disclosure — an axis about volume, entirely independent of trust.
Evidence
How trustworthy a number is: the five-tier ladder above. The fill of the disc is the confidence ladder; the hue carries no meaning.
Node export
The cross-node currency — a JSON document a node emits for the bus, carrying the recording’s anchor and its list of events. It is the only thing nodes exchange; they never call each other.
Floating wall-clock time
The suite’s canonical time unit: the recording’s local civil time encoded as if it were UTC. Wearables speak local time with no zone, so storing a real instant and rendering it with local getters would make a New-York night read as 03:00 in London. Floating time is viewer-timezone-independent by construction, and two devices recording the same wall-clock minute produce the same value without anyone sharing a timezone.
Local-only
Not a policy but a property: every analyzer is one self-contained file that runs in your browser. There is no upload, no account, no backend, and no network fetch of any kind — a gate refuses to ship a page that adds one.
Naming a new node? The recipe, the capitalization rules and the full naming system live in docs/LEXICON.md. Branding becomes systematic through that document — not through renames.

Intended use & safety

Tepna computes biometric patterns from your wearable and sensor data to support personal self-quantification. It is not a medical device, does not diagnose, treat, cure, screen for, or prevent any disease or condition, and is not a substitute for professional clinical evaluation. Always consult a qualified healthcare provider about your health. For research and personal use only. 100% local — no data leaves your device.
